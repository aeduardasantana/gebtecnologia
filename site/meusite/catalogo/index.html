02 / Como funciona

Uma lista, muitas possibilidades.

O que posso colocar no campo de detalhe?

Preço, observação, condições ou uma frase curta. É um campo genérico e opcional.

Para onde posso enviar o visitante?

Para links HTTPS de WhatsApp, formulários, lojas, pagamentos, agendamentos ou outros destinos válidos.

Quantos itens podem ser adicionados?

O catálogo foi pensado para crescer com o negócio. Em listas extensas, o editor poderá carregar os itens progressivamente.
