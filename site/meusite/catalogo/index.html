COMO FUNCIONA

Informações fáceis de encontrar

O visitante encontra o item, consulta o preço ou a observação informados e abre o destino definido pelo proprietário.

Posso usar links de WhatsApp ou pagamento?

Sim. Cada item pode apontar para um endereço HTTP ou HTTPS válido, inclusive uma conversa de WhatsApp ou página de pagamento.

O campo de preço é obrigatório?

Não. Você pode preencher uma observação, um preço ou deixar o campo vazio.

Posso adicionar mais itens?

O formato prevê uma lista extensível. O editor definitivo ainda está em desenvolvimento.
